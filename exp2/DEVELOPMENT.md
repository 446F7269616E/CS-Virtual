# 实验二开发说明

## 模块目录

- `experiment2.ipynb`：VS Code 中按顺序运行的实验单元，显示代码、输出与图片。
- `experiment2.py`：与 Notebook 相同的实验流程，支持一次运行并保存结果。
- `image_ops.py`：读取图像、噪声转换、OpenCV 滤波、手写彩色中值滤波。
- `plotting.py`：统一生成对比图并保存。
- `p1.jpg`：用户提供的 480×360 彩色图像，保留原始文件内容。
- `output_images/`：程序实际生成的实验结果图。
- `assets/`：在 VS Code 中截取的真实运行截图。
- `README.md`：参照实验一编写的实验报告。

## 开发规范

图像处理与绘图分开，Notebook 和脚本复用相同函数。显示时使用 RGB；灰度图单独处理。噪声生成使用固定随机种子，所有 OpenCV 滤波均使用相同的 uint8 输入及 5×5 窗口。手写中值滤波逐通道、逐像素处理，以边缘复制填充，并验证窗口和输入格式。

噪声参数按参考文档：椒盐 amount=0.4，高斯 mean=0.2、var=0.03。说明高斯噪声包含正均值偏移，不能声称平滑滤波可以完全恢复原始亮度。

## 运行与交付

复用已有 Conda `cv` 环境。按用户此次明确要求实际运行实验并截图，不额外建立测试套件。只提交实验二的源码、依赖、输入图、结果图、截图和报告；环境、临时缓存不提交。
